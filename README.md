# cbpi4-ActorTempStep

Плагин шага ActorTemp для CraftBeerPi 4.

## Описание

Универсальный шаг, который управляет выбранным устройством при достижении заданной температуры. Плагин позволяет:

- Задать целевую температуру для срабатывания
- Включить или выключить выбранное устройство при достижении температуры
- Добавить задержку (в минутах) перед выполнением действия после достижения температуры
- Управлять режимом AutoMode (PID/гистерезис) котла: оставить включенным или выключить
- Автоматически перейти к следующему шагу после выполнения действия
